# Project notes

The previous game (Break of Day) was scrapped on 2026-10-13. Its full code (v0.15) is kept on the
`archive/break-of-day` branch. This repo is a clean slate for the next game.

## Versioning (standard for every game here)
- Player-facing version is `v0.NN`, +0.01 per shipped build; `v0.00` means nothing shipped yet. Show it in the game's main menu
  (put the internal build id in a tooltip, not on screen).
- `BUILDS.json` is the build log: version, internal 6-char build id, commit, date, notes.
- Normal builds: `python3 build.py`. When shipping (commit + push): `python3 build.py --ship "short notes"` once, then commit,
  then fill the previous entry's `commit` field on the next ship.
- `version.json` carries the build id (for client auto-reload) and the version.
- The page is served by GitHub Pages from `index.html` at the repo root.

## Current game: Hold the Line (working title) — 1vX tower defense

sapper keeps 4 via `fixedDmg`), attacker starts with 30g per lane and earns nothing during setup; income grows only from sending (+0.21% of gold sent, `sendIncome`; Invest was removed; `noIncome` units like the 40g sapper give none), hoarding counter (`atk.hoard`: +1%/s up to 65% whenever the bank is over 60g (`hoardBank`) during open sending, frozen in setup/pause; bar on each lane chip), units move at 95% (`RULES.unitSpeed`), sends open 30s / pause 15s (`sendPhase`, `canSend`; sim flags `noPause`, `gate`, `sendInc`, `hoardTax` (false disables), `spdMul`, `spdStep`, `botMix` (attacker bot saves for each rolled unit) and `botHold()` (bot chooses to hold gold) are for bot tests), level-up rebuild 1.5s (`levelTime`), 10s setup at the start (`RULES.setup`, no sends; unlock minutes and the 20-min window count from its end), full refund for towers sold within 10s of placing that haven't dealt damage (`refundable`), no waves: attacker sends spawn immediately (`spawnAt`, staggered per lane via `laneNext`), 20-min send window then finish-out, 22 attacker units (menu order runner, grunt, footknight first; Ogre and the zombie/skeleton hordes unlock at 2:00) with unlock minutes/packs/armor/resists and traits (`UNITS`; sapper sprints off-lane via `stepSapper` and knocks towers out (`t.off`), knight `charge`, troll `regen`, gnoll `packRage`, necro `raise` from `graves`, mammoth `spill`, shield `frontGuard`, golem/ent/ram damage multipliers), attacker upgrade: unit speed +5%/level x5, new spawns only, defender spells (`SPELLS`: Meteor 125g + Water Jet 100g, 20s cooldowns;
